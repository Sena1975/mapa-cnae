**Mapa CNAE** é um projeto Laravel para consulta e cache de geocodificações e lugares, com foco em performance de busca por praças e endereços.

Este site documenta:

- Como instalar e configurar o projeto;
- Estrutura de banco (SQLite por padrão);
- Comandos de linha de comando (Artisan), incluindo `mapa:warm`;
- Dicas de desempenho e troubleshooting;
- Como inspecionar o banco via DBeaver.
